# 🎸 GrooveTui

**GrooveTui** é um assistente de guitarra minimalista para terminal. Desenvolvido em **Rust**, ele une a eficiência das TUIs (Terminal User Interfaces) com o estudo prático de música.

O objetivo do GrooveTui é ser o companheiro ideal para suas sessões de prática, oferecendo um metrônomo estável e, em breve, um gerador inteligente de harmonias.

## ⚡ Funcionalidades

- **Metrônomo Multi-thread:** O som não engasga, mesmo quando você redimensiona o terminal.
- **Interface Ratatui:** Navegação rápida e visual moderno no terminal.
- **Controle de Tempo:** Ajuste fino de BPM em tempo real.

## 🛠️ Stack Técnica

- **Rust** (Core)
- **Ratatui** (Interface)
- **Rodio** (Audio Engine)
- **Crossterm** (Backend de Terminal)

## ⌨️ Comandos

- `Espaço`: Play/Pause no metrônomo.
- `Seta para Cima`: Aumentar BPM.
- `Seta para Baixo`: Diminuir BPM.
- `Q`: Sair com segurança.
